turbowarp-http-server-cloudflare

Cloudflare Workers TypeScript/Hono generation support for the turbowarp-http-server family.

Blocks

Cloudflare handler [METHOD] [PATH] returns [BODY]

Creates a minimal HTTP handler IR JSON entry.

Cloudflare Worker [NAME] with handlers JSON [HANDLERS]

Creates a Worker IR JSON document from handler entries.

generated Cloudflare files JSON from IR [IR]

Runs the generator and returns GeneratedFile[] as JSON.

Target

The MVP target is Cloudflare Workers with TypeScript and Hono. External OAuth/OIDC providers and Cloudflare storage bindings are represented in the IR, while direct browser-side deploy is out of scope.
